# University Grade Portal

This is our group project for CMPS 380. We are building a website
where students can view their grades, instructors can manage grades
for their courses, and admins can manage accounts and permissions.

All users will log in with a password, face verification,
and a liveness check.

## Main Features
- Student sign-up and admin approval
- Face registration
- Password and face verification at login
- Different access permissions for each role
- Viewing and updating grades
- Recording important actions in an activity log
